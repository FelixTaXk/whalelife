# 插件开发约束

必须遵守仓库根目录 `AGENTS.md` 和 `architecture/PLUGINS.md`，本机交接从 `docs/HANDOFF-PLUGINS.md` 进入。独立仓库发布插件时，也须将公开契约及其版本基线作为开发依据。

- 只修改正在开发的插件及其测试、文档，不修改主干或无关插件来完成业务功能。
- 只调用公开接口；不得运行时导入 `core/`、操作主干实例或访问主干私有文件/API/样式。
- 不假定新宿主独有能力存在。使用新增能力要声明要求并检查可用性；已有能力与旧数据必须继续兼容。
- 资源和请求遵守 `ctx.signal`、`ctx.effect`；捕获自己的业务异常，不使用 `process.exit`，不修改共享全局状态。插件数据迁移归本插件负责。
- 发布前在声明支持的最低宿主与当前宿主上验收；插件停止、失败、重载不得破坏主干及无关插件。不能通过修改冻结的兼容样本让测试通过。
